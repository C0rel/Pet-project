# Игра "Угадай число"

Консольная игра на Go, в которой нужно угадать случайное число за ограниченное количество попыток.

---

## Запуск

### Требования
- Go 1.25.3 или выше

### Локальный запуск

```bash
# Клонировать репозиторий
git clone https://github.com/C0rel/Pet-project.git

# Перейти в папку проекта
cd Pet-project

# Установить зависимости
go mod tidy

# Запустить игру
go run main.go
