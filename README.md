# Игра "Угадай число"

Консольная игра на Go, в которой нужно угадать случайное число за ограниченное количество попыток.

---

## Запуск

### Требования
- Go 1.18 или выше

### Локальный запуск

```bash
# Клонировать репозиторий
git clone https://github.com/ТВОЙ_НИК/guees_the_number.git

# Перейти в папку проекта
cd guees_the_number

# Установить зависимости
go mod tidy

# Запустить игру
go run main.go
